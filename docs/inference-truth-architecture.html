Inference Truth

Decentralized AI inference. The Inference Service sends each prompt to the model the user chose, then calls the Verification Service to re-check a sample on Machine 3. A Monad smart contract settles the result in MON: pay on PASS, slash on FAIL.

Off-chain compute On-chain · Monad Verification path Reward Slash
  1. INFERENCEPrompt + payUser or AI agent sends a prompt with 1B or 2B to the Inference Service and locks MON.
  2. INFERENCERouteInference Service calls Machine 1 for 1B or Machine 2 for 2B.
  3. INFERENCEAnswerAnswer A goes back to the user and the request is recorded on-chain.
  4. VERIFICATIONVerifyInference Service calls the Verification Service, which samples and re-runs on Machine 3 for Answer B.
  5. VERIFICATIONCompareSemantic similarity of A and B decides PASS or FAIL.
  6. MONADSettle on MonadVerification Service sends the verdict tx to InferenceTruth.sol.
  7. MONADPay or slashPASS pays provider + verifier. FAIL slashes stake.

Monad never runs the LLM. It holds the MON, the stakes and the rules, and every contract call pays gas in MON. Similarity score and threshold shown are examples.
